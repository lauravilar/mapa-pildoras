# Mapa de píldoras

Sitio estático para GitHub Pages. No necesita compilación ni conexión a otros servidores.

- `index.html`: el mapa. No hay que tocarlo al añadir píldoras.
- `pildoras.js`: los datos. Una entrada por píldora: `id` (estable, p. ej. `3.02`), `titulo`, `lema`, `video`, `portada`, `esencial` y `sintomas`.
- `c1/` … `c5/`: vídeos y portadas de cada capítulo.

Enlace directo a una píldora: `…/index.html#3.02`.
